# CLAUDE.md 생성기 (간결·절약형)

CLAUDE.md는 **대화를 시작할 때마다 통째로 로드**된다. 그래서 한 줄 한 줄이 매번 드는 토큰이다.
목표는 "코드를 뒤지지 않으면 알 수 없는 것"만 한 장에 담는 것.

## 절차

1. **수집**: 읽기만 하고, 필요한 만큼만 본다.
   - 루트 목록과 2단계 트리. `node_modules` `.git` `dist` `build` `venv` `__pycache__`는 뺀다.
   - 매니페스트(`package.json` `pyproject.toml` `requirements.txt` `go.mod` `Cargo.toml` …)에서 언어, 프레임워크, scripts를 확인한다.
   - 설정: `tsconfig`, 린터·포매터 설정, 배포 파일(`vercel.json` `Dockerfile` CI)
   - `README.md`에서 목적을 한 줄로 뽑는다.
   - 기존 `CLAUDE.md`가 있으면 **압축 모드**로 간다. 템플릿대로 다시 쓰고, 의미가 빠진 줄이 없는지 대조한다.
2. **목적 확정**: README나 코드에서 목적이 한 문장으로 안 나오면 사용자에게 **한 번만** 묻는다.
3. **작성**: 아래 템플릿을 따른다. 내용이 없는 섹션은 통째로 지운다.
4. **점검**: 체크리스트를 통과하면 저장하고, 줄 수와 글자 수를 보고한다.

## 템플릿

```markdown
# <프로젝트명>
> <무엇을 하는 프로젝트인지 한 줄> — Claude의 일: <이 레포에서 주로 할 작업>

## 기술 스택
- <언어/런타임 + 메이저 버전>
- <프레임워크 / DB / 인증 / 스타일링>

## 구조
<dir>/        # <역할>
  <subdir>/   # <역할>

## 명령어
- 실행: `<cmd>`
- 테스트: `<cmd>`

## 규칙
- <언어>: <네이밍>, <필수 사항>
- 스타일: <포매터/린터>

## 주의
- <모르면 사고 나는 것: 건드리면 안 되는 파일, 생성 파일, 수동 절차, 환경변수 이름(값은 X)>
```

## 절약 규칙

- **30줄 이하를 목표로 하고, 60줄을 넘기지 않는다.** 넘으면 줄을 합치거나 지운다.
- 문장으로 풀어 쓰지 않는다. `키: 값`, 불릿, 한 줄 주석만 쓴다.
- **적지 말 것**
  - 파일을 열면 바로 보이는 것: 의존성 전체 목록, 함수 목록, 린터가 이미 강제하는 규칙
  - 일반론: "깔끔한 코드", "테스트 잘 작성", "보안 주의"
  - README 복붙, 설치 튜토리얼, 변경 이력, 자주 바뀌는 행 번호
- **꼭 적을 것**
  - 목적 한 줄(이 대화가 무엇을 위한 것인지)
  - 실행·테스트·빌드·배포 명령어. 실제 파일에서 확인한 것만 적는다.
  - 도구가 강제하지 않는 팀 규칙
  - 함정: 비표준 구조, 건드리면 안 되는 파일
- 긴 문서는 복사하지 말고 경로만 적는다. 예: `API 명세: docs/api.md`
  - `@파일` import는 쓰지 않는다. 대화 시작 때 같이 로드돼서 토큰이 절약되지 않는다.
- 모노레포는 폴더별 `CLAUDE.md`(`backend/CLAUDE.md` 등)로 나눈다. 해당 폴더에서 작업할 때만 로드된다.
- 트리는 2단계까지, 의미 있는 폴더만 적는다. 파일 하나짜리 앱이면 핵심 파일과 그 안의 구획을 적는다.
- 설명은 사용자 언어로 쓰고, 식별자와 명령어는 원문 그대로 둔다.
- 시크릿과 키 값은 절대 적지 않는다.

## 체크리스트 (저장 전)

- [ ] 처음 두 줄만 읽어도 무슨 프로젝트이고 Claude가 무슨 일을 하는지 안다
- [ ] 줄마다 "이 줄을 지우면 Claude가 실수하거나 탐색에 토큰을 더 쓰나?"를 묻는다. 아니면 지운다.
- [ ] 빈 섹션, 중복, 일반론이 없다
- [ ] 명령어와 경로는 전부 실제로 확인했다
- [ ] `wc -l -m CLAUDE.md`로 줄 수와 글자 수를 확인했다

## 예시

```markdown
# ShopAPI
> 쇼핑몰 주문/결제 API + 관리자 웹 — Claude의 일: 기능 추가·버그 수정

## 기술 스택
백엔드
- FastAPI (Python 3.11)
- PostgreSQL + SQLAlchemy
- JWT 인증
프론트엔드
- Next.js 14 (TypeScript)
- TailwindCSS

## 구조
backend/app/
  api/      # API 라우터
  models/   # DB 모델
  schemas/  # Pydantic 스키마
frontend/   # Next.js 앱

## 명령어
- 백엔드: `cd backend && uvicorn app.main:app --reload`
- 프론트: `cd frontend && npm run dev`
- 테스트: `pytest` / `npm test`

## 규칙
- Python: snake_case, type hints 필수
- TypeScript: camelCase, strict mode
- 스타일: Black, Prettier

## 주의
- DB 모델을 바꾸면 `alembic revision --autogenerate` 필수
```
