# 음악 스킨 기능 테스트 (Wallpaper Engine)

음악 스킨을 본격적으로 만들기 전에, Wallpaper Engine에서 필요한 기능이 실제로 되는지 확인하는 테스트 배경화면입니다.
화면 오른쪽 **기능 테스트 결과**에 각 항목이 ✅ / ❌ 로 표시됩니다.

## 설치 (Windows)
1. 이 `wallpaper-test` 폴더를 통째로 PC에 받습니다.
2. 아래 둘 중 하나로 넣습니다.
   - **방법 A:** 폴더를 `Steam\steamapps\common\wallpaper_engine\projects\myprojects\` 안에 복사한 뒤, Wallpaper Engine을 다시 엽니다.
   - **방법 B:** Wallpaper Engine 하단 **Wallpaper Editor** → **Create Wallpaper** → 이 폴더의 `index.html` 선택
3. 배경화면 목록에서 **음악 스킨 기능 테스트**를 적용합니다.

## 테스트 순서
1. Spotify나 YouTube Music(브라우저) 등에서 **아무 곡이나 재생**합니다.
   - 왼쪽에 곡 정보와 앨범아트, 가운데에 가사가 뜨는지 봅니다.
2. 화면 아무 곳이나 **클릭**합니다.
3. 아래 입력칸을 클릭하고 **타이핑**합니다.
4. ①②③ 버튼을 하나씩 눌러 **브라우저나 Spotify 앱이 열리는지** 봅니다.
5. 오른쪽 결과 화면을 캡처해서 공유해주세요. ①②③ 결과도 같이 알려주세요.

## 항목 설명
| 항목 | 확인하는 것 |
|---|---|
| 미디어 연동 6개 | 지금 재생 중인 곡 정보, 앨범아트, 색상, 재생 상태, 진행 시간을 받을 수 있는지 |
| 가사 API (LRCLIB) | 배경화면 안에서 외부 가사 서비스를 호출할 수 있는지 |
| 검색 API (iTunes) | 배경화면 안에서 음악 검색 결과를 받아올 수 있는지 |
| 유튜브 영상 재생 | 뮤직비디오 배경용 유튜브 영상을 틀 수 있는지 |
| 로컬 mp4 재생 | 내려받은 영상 파일을 배경으로 틀 수 있는지 |
| 마우스 / 키보드 | 위젯 클릭, 검색창 타이핑이 되는지 |
| 링크 · 앱 열기 | 배경화면에서 외부 브라우저나 Spotify 앱으로 넘어갈 수 있는지 |

## 참고
- 미디어 연동이 ❌이면 Wallpaper Engine 설정에서 미디어 연동 관련 옵션이 켜져 있는지 확인해주세요.
- 유튜브에서 **오류 153**이 나오면, 로컬 파일로 연 페이지라 유튜브가 출처 정보를 받지 못한 것입니다. 이 경우 웹에 올린 페이지를 거쳐 영상을 띄우는 방식으로 우회합니다.
